# Gateway 用户详情公共 UI

用户详情的资料、预算、用户密钥、最近请求和用户审计采用公共 PageHeader、Field、Input、Textarea、Select、Switch、ControlButton、Dialog、Table、Badge 与状态反馈。页面消费既有明暗主题。桌面资料和密钥使用双列卡片，窄屏表单单列，宽表在各自容器内滚动。四语言原有各 1496 项文案保持，各增加 15 项详情反馈；包清单和锁文件保持，新增依赖为零。复制控件移到 `components/GatewayCopyControl.tsx`，内容字节保持，密钥页面继续通过公共入口消费。

## 读取和写入契约

页面拥有资料、密钥、最近五条请求、最近五条审计和计费币种的五个读取操作。每个请求覆盖完整响应 body 的 20 秒预算，替换、离页和卸载会取消。详情的预算字段与两个费用表共用一个已校验币种。成功读取且未配置币种时使用网关声明的 USD 默认值；非法已存配置或读取失败显示错误，在确认币种前暂停业务编辑和费用展示。主动重读成功后恢复。错误保留安全的服务端信息和关联 ID，HTTP401 交给既有会话所有者处理。

用户身份在当前路由生命周期解析为 UUID。包含百分号、斜杠和中文的外部身份沿用实测解码边界，外部身份修改后的回读使用该 UUID。用户 metadata 的 false、零、数组、字符串和 null 保持实际 JSON 值；空草稿沿用保留原值语义。PostgreSQL NUMERIC/DECIMAL 费用文本严格转成有限数值；损坏审计 snapshot 和 changed_fields 明确失败。

所有写入共用同步保护，阻止同帧重复提交。用户 PATCH 可能先写入资料再在预算处理失败，因此失败保守呈现为需要确认当前状态。创建密钥的明确 HTTP400 可以修正输入；响应丢失、网络失败及其他写失败保留草稿并锁定后续写入。用户显式回读成功才解除保护，失败回读继续保护。密钥操作只回读密钥和审计，资料草稿保持；资料保存回读资料和审计。删除用户保留既有请求、审计历史与其他用户的密钥。

## 真实验证

Apple Silicon macOS、Next 16.2.3、真实 PostgreSQL、Chromium 153、Clipboard 和 loopback HTTP 验证通过：19 项页面流程、14 项读取/写入生命周期、14 项 metadata 回归及实际 V8 调用次数检查。五宽度 1440/1024/820/390/320 × 明暗主题、四语言 320px 表单通过，桌面浅色和中文手机深色截图已人工查看。受影响 ESLint、Next webpack 生产构建、standalone 和 TypeScript 通过。预算部分写入、实际 socket 中断、不完整 body、非法存储、NaN 费用、坏审计 JSON、401 和取消均在实际边界验收。

资料输入六个字符时，三张未变化表格的实际函数调用分别从 6 次降为 0 次；真实密钥操作仍更新密钥和审计表。公共 Dialog 的关闭/取消恢复触发控件焦点，创建/删除成功后返回页面标题区域。

## 性能与成本决定

20 密钥、五请求、五审计、1440×900，同数据库真实会话，禁用缓存并在 heap 采样前执行 GC；四预热、64 个 ABBA/BAAB 正式样本。就绪 109.45→111.95ms（+2.28%），heap 5617318→6482064 bytes（+15.39%），滚动 P95 16.80ms 保持；冷打开密钥表单 46.00→61.40ms（+33.48%），弹窗 heap 5851182→6873422 bytes（+17.47%），输入 8.40→9.15ms（+8.93%），关闭观测 heap 6059076→7188720 bytes（+18.64%）。打开指标包含 locator 观测，关闭指标在表单隐藏时采样。首屏实际请求 gzip 228778→234286 bytes（+2.41%），完整静态 gzip 702446→706292 bytes（+0.55%）。

独立 48 次相同输入的真实开关调查，在退出动画完成和焦点恢复后观测：候选 DOM nodes 1385、监听器 613 在第 1/12/36/48 次保持；第 1→48 次普通 object 增加 3788 bytes、closure 保持，code 类增加 1222484 bytes。旧页面对应 code 增加 463368 bytes。聚合证据支持主要增长位于 V8 code 类；完整原始 heap 只在内存处理，未持久化。该调查不证明所有泄漏路径，也不能把 code 类细分为特定优化来源。

性能技术状态为 INVESTIGATE。本详情批的成本决定独立记录，认证/导航、供应商、API 密钥和用户列表的成本决定继续保持各自范围。产品候选保留在本任务分支，具备相应成本决定后执行本地集成和主仓复验。
