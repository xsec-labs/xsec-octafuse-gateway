配置读取和保存各有独立请求所有者、取消与完整正文20秒预算。离页取消所属请求；组件释放后不再启动后续 Webhook 保存。真实401交给既有会话所有者移除内容。时区保存成功刷新现有业务时区 Provider，并保持页面身份。
